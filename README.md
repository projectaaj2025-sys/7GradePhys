# Сюда кладут скриншоты

Здесь лежат картинки, на которые ссылается `README.md`. Сейчас их нет — снимите кадры сами
(2–3 штуки достаточно):

1. открыть `index.html`;
2. снять меню, игровой экран и окно задания;
3. сохранить сюда как `menu.png`, `level.png`, `task.png` (или `.jpg`, ширина ~1200 px);
4. раскомментировать блок «Кадры из игры» в `README.md`;
5. `git add docs/img && git commit -m "docs: скриншоты игры"`.

Требования, чтобы репозиторий оставался удобным:

- **без лиц учеников** и без кадров экрана с персональными данными (журнал, почта, чаты);
- если на снимке видно имя пилота — лучше вписать нейтральное (`Пилот 7А`);
- вес одного файла до ~300 КБ (PNG для текста, JPG для фото-фона); гифки не нужны;
- тёмная/светлая тема: игра сделана в светлой — скриншоты в ней и делайте.
